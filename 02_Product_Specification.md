# 02_Product_Specification

## Overview

Atlas is a single-page interactive developer portfolio built as a
persistent world.

## Core Features

-   Persistent world
-   Click-to-travel navigation
-   Interactive destinations
-   Project showcase
-   Skills
-   Experience
-   Contact section
-   Responsive layout

## Technical Requirements

-   Next.js
-   TypeScript
-   React Three Fiber
-   GSAP
-   Tailwind CSS

## Non-Functional Requirements

-   Accessible
-   Responsive
-   Fast loading
-   Smooth animations
-   SEO-friendly
-   Lighthouse score target: 90+

## Constraints

-   No authentication
-   No backend for v1
-   No CMS
-   Desktop-first with mobile support

## Definition of Done

The application is stable, accessible, performant, and deployable as a
static portfolio.
