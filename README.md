# Project Atlas

An interactive portfolio presented as a persistent world of exploration.

## Vision

Atlas is a single-page experience where visitors travel between
destinations to discover projects, skills, experience and contact
information.

## Stack

-   Next.js
-   React
-   TypeScript
-   Three.js / React Three Fiber
-   GSAP
-   Tailwind CSS
